# UI Quality

The app should feel like a game companion, not a developer asset browser.

## Acceptance Criteria

- No raw archive framing or developer-facing filenames visible in the UI
- No tables used for user-facing content (tables are for data, not browsing)
- List pages are light and browsable, not overstuffed
- Heavy detail belongs on detail pages (`/<entity>/<id>`), not list pages
- No aggressive image cropping that destroys the artwork
- No unnecessary ID badges, file paths, or metadata clutter
- Unlocalized strings are cleaned up in both en.json and ja.json
