# Home Page

The home page is a minimal, scalable hub that surfaces secondary sections and photo sets.

## Acceptance Criteria

- Home page loads quickly with minimal visual weight
- Navigation tiles or links to all secondary sections are clearly visible
- All available photo sets (e.g. `photo_10512/final`) are rendered in a simple image grid at the bottom of the page
- Photo grid just shows the images — no fancy gallery, no lightbox, just a grid
- The page does not feel like a developer dashboard or asset dump
- The page scales gracefully as new sections are added
