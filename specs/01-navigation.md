# Navigation

The top navigation bar should contain only core routes: Home, Cards, Stories, Songs, Characters.

All secondary sections (Gacha, Stickers, Downloads, BGM, Grand Prix, Items, Emoji, Viewer, Spine Viewer) should be accessible from the home hub, not the top bar.

## Acceptance Criteria

- Top nav displays exactly five links: Home, Cards, Stories, Songs, Characters
- No secondary routes appear in the top nav
- The home page provides navigation tiles or links to all secondary sections
- Navigation feels clean and uncluttered at all viewport sizes
