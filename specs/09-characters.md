# Characters

Character pages use card art as the primary visual anchor and profile asset families in secondary positions.

## Profile Asset Families

- `image_prof_data_chara_*`: fan-level/profile badge assets, not full portraits
- `image_prof_data_chara_season_*`: seasonal variants of the above
- `image_prof_custom_*`: tied to specific cards, useful on detail pages
- `image_prof_etc_*`: exists in bundle catalog but not yet surfaced in the app

## Acceptance Criteria

- Character list page uses card art as the main visual for each character
- Character detail page shows card art prominently
- Profile asset families appear in secondary/profile sections, not as main portraits
- `image_prof_etc_*` family is surfaced somewhere appropriate when extraction is available
