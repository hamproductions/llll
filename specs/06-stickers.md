# Stickers

The sticker page provides smart default filtering so users see useful stickers first.

## Category Semantics

- CategoryName 4: legacy/title junk — hidden by default
- CategoryName 2: card unlock commemorative — useful
- CategoryName 3: campaign/promo — useful
- CategoryName 1: login/milestone — useful

## Acceptance Criteria

- Default view hides CategoryName 4 (legacy/title stickers)
- Toggle presets available: Recommended, Card Unlock, Campaign, Milestone, Legacy, All
- Sticker grid is visually browsable without feeling like a dump of all categories
- Search or filter functionality allows finding specific stickers
